PixelTavern 像素酒馆

像素风黑暗奇幻酒馆 AI 模拟前端。用 LLM 驱动 NPC 在酒馆中自主交互——对话、移动、坐下、离店、打盹。

Phaser 3 + TypeScript + FastAPI + SQLite | OpenAI-compatible API

愿景：让 AI 角色互动像走进一间有血有肉的奇幻 RPG 酒馆。

核心循环：配置 LLM → 启动世界轮次 → NPC 自主行动 → 用户干预 → 历史回放/导出/分享

功能：像素酒馆地图 · NPC A* 寻路 · 坐姿/行走/说话动画 · 角色 CRUD · 世界轮次运行 · 历史回放 · 状态导出/导入 · 用户干预 · 长期记忆 · 5 种风格预设 · 自定义风格

暂缓：PNG 角色卡导入 · PWA · Tauri 桌面端 · 角色市场 · 插件系统

GitHub: songzijiang/PixelTavern

实验功能仍在开发中，可能不稳定。
