# 🍺 PixelTavern · 像素酒馆

> 推开木门，炉火噼啪作响。四个灵魂正在等你。

**像素酒馆** 不是聊天机器人，也不是文字冒险游戏。它是一间活着的酒馆——大语言模型驱动 NPC 在这里喝酒、争吵、密谋、打盹，而你可以推开那扇门，走进去，成为故事的一部分。

更多介绍参见[B站](https://www.bilibili.com/video/BV1xC5i6SEpr)

---

## 这间酒馆里有什么

你推开厚重的木门，首先看到的是一间完整渲染的像素风酒馆：吧台后面，酒保在擦杯子；壁炉旁，勇士靠着墙，手边放着剑；角落最暗的那张桌子，神秘客的紫眼在兜帽下发光；二楼飘下草药和雷雨的气味——女巫下来了。

他们不是在等你点击"发送"。即使你什么都不做，他们也已经在交谈、走动、坐下、叹气、互相打量。

关键是他们有**记忆**。五分钟前勇士说的话，酒保会记得。昨夜的冲突会影响今天的氛围。你可以在任何时候插入一句旁白——"门外传来马蹄声"——所有人会看向门口。

每一轮结束，你可以回放刚发生的剧情，导出存档，或者分享给朋友。如果你不喜欢默认的角色和故事，你可以换掉酒馆的"风格"——风格不只是皮肤，它会改变每个角色的身份、性格、说话方式，甚至酒馆所在的整个世界。

## 快速开始

### 1. 获取 DeepSeek API Key

像素酒馆默认使用 [DeepSeek 官方 API](https://platform.deepseek.com/) 驱动 NPC。

1. 访问 [platform.deepseek.com](https://platform.deepseek.com/) 注册账号
2. 进入 [API Keys 页面](https://platform.deepseek.com/api_keys) 点击"创建 API Key"
3. 复制生成的 key（以 `sk-` 开头）
4. 冲5块钱足够体验数小时剧情

> DeepSeek 是国内访问最稳定、中文对话质量最高的 LLM 之一。支持 OpenAI 兼容接口，像素酒馆也兼容其他 OpenAI-compatible 的 API（如 OpenAI 官方、Ollama 本地部署等）。

### 2. 启动酒馆

双击 `PixelTavern.exe` 即可启动。首次运行如果需要修改配置，则关闭 exe，在 `~/.pixeltavern` 中修改 LLM 配置。

### 4. 开始你的故事

1. 打开浏览器访问前端地址（默认 Vite 开发端口 `8000`）
2. 首次运行时阅读并同意免责声明
3. 点击「LLM」选项卡，填入 DeepSeek API Key 和模型名称（推荐 `deepseek-v4-flash`），点击保存
4. 回到「世界」选项卡，并点击屏幕下方控制台 ▶ 开始 按钮，然后享受这段独属于你的故事吧

NPC 会自动开始他们的生活。你可以在下方输入框中写任何东西来影响剧情。

## 不只是聊天：这间酒馆能做什么

### 世界轮次系统

酒馆以"轮次"运行。每一轮（约 30 秒），LLM 会根据当前状态——谁在哪里、刚才说了什么、谁和谁的关系如何——生成 5-8 句对话和若干动作。NPC 通过 A* 寻路在酒馆里走动、找椅子坐下、走到吧台前点酒、累了靠墙打盹。

轮次制意味着：你可以暂停，可以回放任意历史轮次，可以导出整个世界的存档分享给别人。

### 多种内置风格 + 无限自定义

部分默认四套世界观各有自己的角色阵容和故事基调：

- **灰烬边境** — 黑暗奇幻，边境酒馆，秘密交易与灰色人物。这是默认风格，也是你第一眼看到的酒馆。
- **猩红宫廷** — 权谋暗涌，血色宫廷。角色关系盘根错节，每句话都有潜台词。
- **佣兵日常** — 轻松佣兵喜剧，粗粝但温暖的江湖日常。
- **雾港谜案** — 哥特式悬疑，海雾中的秘密。

你也可以创建自己的风格：指定每个角色的身份、性格、说话方式、背景故事。自定义风格可以导出为 zip 分享，也可以导入别人创作的风格。

### 角色管理

每个风格中的角色都是可编辑的。你可以修改他们的名字、外观素材、性格特质、说话风格，以及他们与其他角色的关系描述。LLM 会在生成对话时遵循这些设定。

### 场景编辑

打开"场景"选项卡（需要在设置中开启实验功能），你可以拖拽调整家具位置、碰撞区域、门的位置，让酒馆布局完全按照你的想法来。

### 素材导入

在"素材"选项卡中，你可以下载动画模板，用 AI 图像生成工具（推荐 GPT image-2）按模板生成 9 组 × 5 帧的角色动画，然后导入成为新角色的可用素材。

### 每日要闻注入

打开每日新闻引导后，酒馆会在每天首次运行时注入一条真实世界的新闻摘要。NPC 会自然地把它带入对话——"你听说了吗？报纸上说……"——让虚拟酒馆与现实世界产生微妙的联系。

## 配置参考

首次启动后，所有配置集中在 `~/.pixeltavern/data/pixel_tavern.json`：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `server.host` | API 监听地址 | `0.0.0.0` |
| `server.port` | API 监听端口 | `8000` |
| `llm.base_url` | LLM API 地址 | `https://api.deepseek.com` |
| `llm.api_key` | API 密钥 | 空（需填写） |
| `llm.model` | 模型名称 | `deepseek-v4-flash` |

也可通过环境变量覆盖：

| 环境变量 | 对应配置 |
|----------|----------|
| `OPENAI_COMPATIBLE_BASE_URL` | `llm.base_url` |
| `OPENAI_COMPATIBLE_API_KEY` | `llm.api_key` |
| `OPENAI_COMPATIBLE_MODEL` | `llm.model` |
| `PORT` | `server.port` |
| `PIXELTAVERN_DATA_DIR` | 数据目录 |

> `OPENAI_COMPATIBLE_BASE_URL` 可填写带或不带 `/v1` 的地址，后端会自动拼接 `chat/completions`。
